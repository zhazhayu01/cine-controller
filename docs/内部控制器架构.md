# Cine Controller 1.0 架构

## 模块职责

| 模块 | 职责 |
| --- | --- |
| `core/properties.py` | 镜头参数、震动事件及内部数据引用 |
| `core/rig.py` | 绑定、目标解析、反推、独立化与解除 |
| `core/driver_graph.py` | 编译原生简单驱动表达式 |
| `core/controller_shape.py` | 可见曲线控制器 |
| `core/path_follow.py` | 原生路径约束及暂停恢复 |
| `core/dolly_zoom.py` | 主体投影与焦距补偿 |
| `core/shake.py` | 多事件震动末端层 |
| `operators/` | 用户操作、插帧和烘焙 |
| `ui/` | 主面板、折叠高级效果、图标与中文说明 |
| `automation.py` | MCP 与脚本 JSON 接口 |

对象上的 `cine` 保存参数，Camera Data 保存光学与构图。可见 Curve 控制器负责整体变换，相机以其为父级；基础位置和旋转固定为单位变换并锁定，最终结果通过增量位置与四元数应用。

中间值使用独立、无着色节点的 `ShaderNodeTree` 持久化，不是场景物体。空间、光学和震动使用各自数据块，避免参数与输出形成循环依赖。

## 空间与求值

```text
控制器整体变换 + 镜头相对参数
    → 环绕位置、基准朝向、偏移与局部旋转
    → 可选希区柯克基础机位
    → 可选震动末端层
    → 相机增量变换和最终世界矩阵
    → 视口、渲染、保存重载与烘焙
```

内部绕 X 轴 +90° 校正相机零朝向：本地 -Z 前向对应控制空间 +Y，本地 +Y 上向对应 +Z。偏移为镜头右、上、前，局部 XYZ 欧拉约定为俯仰、摇摄、负翻滚。外部原点先转换到控制器本地空间，父级变换只应用一次。

反推先转换参考相机世界位置，再求距离与环绕；朝向去除控制器、环绕和基准旋转后拆成局部角度。写入后验证实际位姿，失败恢复输入。反推要求停用震动与希区柯克，不覆盖已有相关动画或驱动。

运行计算采用原生简单表达式与显式驱动变量，不使用驱动命名空间、逐帧处理器、计时器或增量积分。表达式分段满足长度限制，清除默认映射关键点和修饰器，原样输出数值。`force_update` 供脚本修改参数后显式刷新。

## 样条轨迹

控制器使用一个原生 `FOLLOW_PATH` 约束，以 `offset_factor` 控制进度，前向 +Y、上向 +Z，关闭曲线半径缩放，跟随朝向可选。绑定检查样条数、自身依赖、控制器动画与约束。

暂停时保存基础变换、静音约束并定格当前帧，恢复时先还原基础变换，避免旋转叠加。进度动画保存在原生约束上。相机解除与烘焙不删除控制器或轨迹。

## 希区柯克

机位、方向和光学基准保存在控制器上。主面板距离在该模式中路由到活动距离，有效推进量为附加推拉加上捕获距离与活动距离之差。

几何主体记录基准投影跨度，焦距等于基准焦距乘以基准跨度除以当前跨度；以高度为准，退化时采用宽度，参考点使用光轴深度比。光学输入来自主体包围盒、主体世界矩阵和控制器，不反读相机变换或相机参数。穿过镜头或达到焦距极限时提示失去大小保证。

停用恢复基础运动与原焦距动画。光学数据共享、焦距外部驱动或非透视投影时拒绝启用。

## 程序化震动

事件使用 UUID 集合键，显示名称独立保存，动画和驱动按键寻址；删除前项不会改变其他事件路径。删除只清理对应事件动画，共享动作先复制。

末端图复制基础增量变换驱动，再叠加镜头局部位移与旋转。冲击采用幂次衰减，持续模式采用平滑首尾包络；多频波形与种子相位依赖绝对帧、开始帧和场景帧率。事件分量相加后乘总强度。

基础链切换、事件结构编辑和副本独立化重建末端层，播放只走原生依赖图。停用恢复基础输出并释放震动图，保留事件。希区柯克捕获读取未震动的基础机位，避免二次捕获或焦距呼吸。安装失败恢复基础驱动并清理临时数据块。

## 一致性与生命周期

- 结构修改先检查冲突；需保持机位时读取最终求值矩阵，修改后比较位置和四元数差。
- 计算数据归属明确，副本独立化会重定向输入引用，避免修改另一镜头。
- 烘焙逐帧采样最终位姿与联动焦距，移除驱动后写普通关键帧。
- 普通相机与控制器相机共用目标解析，视角操作使用场景活动相机，不保留局部锁定。
- 测试输出与临时工程不进入发布包。

## 界面与自动化

日常运镜、光学与构图保留在主面板，低频效果默认多层折叠。偏好设置只保存通用选项和新建预设。图标预览注册时加载、注销时释放；通用功能优先原生图标，参数说明独立中文。

`bpy.ops.cine.automation` 接收 JSON 并输出单行 JSON，以 `ok` 判断业务状态。`describe` 返回运行版本、字段、单位与规则。写入明确指定镜头，角度用度；批量参数先验证，失败回滚。接口临时覆盖上下文，不改写客户端全局配置。
