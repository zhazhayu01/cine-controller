# 0.2 内部控制器架构

本文是当前实现依据，取代旧规范中依靠 Empty 层级、Track To 约束和启用时保留画面的规定。

## 数据与场景

摄像机 Object 上的 `cine.*` 是用户输入；原有关键帧路径保持不变。空间原点可为空，默认世界原点。

每台摄像机持有一个内部 `ShaderNodeTree` 数据块，用于保存标量中间结果及原生驱动器。它没有节点、材质用途或场景实例，不是场景对象，不加入任何 Collection，也不参与着色。选用独立数据块是为了隔离 Object 参数求值与中间结果，避免在 Object 或 Camera 数据上形成参数依赖循环。摄像机通过 PointerProperty 持有它，保存文件时自动持久化。

普通绑定不创建 Empty、不创建 `Cine Rig` 集合、不改变场景渲染摄像机。瞄准、对焦、原点目标均由用户自行指定。

0.3 提供可选的“一键创建”入口，只生成一台摄像机与一个用户可见的 Curve 控制器，不生成隐藏层级。曲线由多条 POLY 样条组成，包含圆环、取景框和 +Y 前向箭头；默认不参与渲染。控制器放在 3D 游标处，摄像机初始距离为 5，选择状态落在曲线上。空场景将新相机设为渲染相机；已有渲染相机时不替换。

## 求值

```text
摄像机 cine 参数与目标世界坐标
    → 环绕四元数、轨道位置
    → 基准朝向、空间偏移
    → 目标朝向与四元数球面插值
    → 本地 tilt / pan / -roll
    → 摄像机 delta_location / delta_rotation_quaternion
    → Blender evaluated Camera Matrix
```

基础 `location` 固定为零，基础四元数固定为单位四元数，基础 `scale` 固定为一，并锁定对应交互通道。仅用锁图标无法阻止数值输入，因此基础通道同时由常量驱动器控制。用户在插件面板调整空间参数；最终世界矩阵随参数变化。

曲线模式中，摄像机直接以该 Curve 为父对象，父级逆矩阵为单位矩阵。内部表达式输出曲线本地空间的 Camera Matrix，最终世界矩阵为 `W_controller @ L_camera`。外部 Origin/Aim 的世界位置先乘控制器矩阵的逆，转换到本地空间后再参与计算；曲线的移动和旋转只在父级求值时应用一次。Aim 的上方向以曲线控制空间的 +Z 为基准。

所有运行时表达式都使用 Blender 简单表达式，长度不超过 255 字符，数据依赖通过 Driver Variable 显式声明。使用多个标量中间结果拆分复杂数学运算，不将自定义 Python 函数塞进 Driver Namespace。

新建驱动器时清除默认的 F-Curve 映射关键点和修饰器，直接输出表达式数值。否则默认 Bezier 映射可能将接近端点的旋转矩阵分量吸附到 0/1；0.2.1 的轴向重置也会修复已有内部驱动器的这层映射。

不安装 `frame_change_*`、`depsgraph_update_*` 或 `load_post` 处理器，不依赖计时器和插件面板保持打开。`force_update` 只供后台脚本修改参数后显式刷新；时间线、子帧、目标动画和渲染由依赖图自行求值。

## 位置与旋转规则

位置为 `Origin + Rz(h) Rx(v) (0,-distance,0) + Rpre (offset.x,offset.y,-offset.z)`。

`Rpre = Rz(h) Rx(v) Rbase`，偏移始终处于 Aim 和局部旋转之前。瞄准使用本地 -Z 为前向，+Y 为上方向；极点时采用确定的备用上方向，重合目标时退回未瞄准朝向。四元数沿最短弧插值。

0.2.1 新绑定的 `Rbase = Rx(+90°)`，将 Blender Camera 本地 -Z 前向映射为世界 +Y，本地 +Y 上方向映射为世界 +Z。所有控制角度为零时镜头水平拍摄；Distance 增大时沿 -Y 后退，不改变高度。基础四元数仍为单位四元数，校正只存在于内部空间基准。

局部旋转与旧结构的 XYZ Euler 一致，顺序是 `Rz(-roll) Ry(pan) Rx(tilt)`。因此 Pan/Tilt/Roll 不改变位置。

绑定前基础位置、旋转清零，缩放为一；Distance 和环绕角从零开始，最终位置为 Origin，不再从世界零点反解补偿环绕角。预设 Aim 时，朝向继续按 Aim 参数求值。重新指定 Origin 时仍调整轨道参数和基准朝向，避免 Offset 重复叠加并保持当前画面。停用控制器和烘焙保留当前最终世界位姿。

已有内部控制器不会自动改变空间基准或已有动画。面板的“重置为水平轴向”显式设置水平基准，清零环绕、偏移和局部旋转，保留 Distance、Origin、Aim 及光学参数。重置涉及的通道存在关键帧或驱动器时，拒绝直接覆盖。

删除 Aim 后权重自动归零；删除 Origin 后使用绑定或最近一次重设原点时保存的备用原点。备用值不是目标运动的逐帧缓存，因此删除已经移动过的 Origin 可能使位置回到该备用基准。目标改名不影响关系。

## 面板与复制

Cine 侧栏面板不依赖活动对象类型。控制目标优先取当前选中的摄像机，否则取场景保存的备用摄像机，再回退到渲染摄像机；没有摄像机时仍显示选择提示。选中非摄像机时可在面板顶部切换备用摄像机，启用、停用、升级和烘焙共用此目标解析逻辑。

活动对象是匹配的曲线控制器时，通过曲线上的摄像机指针与摄像机上的控制器指针双向校验，解析到对应相机，不靠对象名称查找。面板顶部的创建入口始终保留。停用/烘焙释放父级绑定并保留世界结果，曲线本身不会被自动删除；再次启用同一相机时可继续使用原曲线。

Blender 原生复制会共享任意 PointerProperty 指向的内部数据块。面板发现副本时提供“独立化摄像机副本”，复制内部数据、重定向输入和输出，保留副本参数动画。停用或烘焙前也会自动独立化，避免删除原镜头数据。不在后台安装拦截复制操作的处理器。

## 兼容与恢复

旧版 Helper 指针暂时保留，仅供显式升级和停用。打开旧工程不会自动升级；面板提供“升级内部控制器”。升级沿用参数、原 Action、基准朝向和原点关系，验证当前矩阵一致后才删除旧 Helper；失败恢复原结构。升级不是重新绑定，不会清零旧镜头。

新绑定拒绝覆盖现存的外部变换动画、驱动器或有效约束。参数动画、Lens 动画、其他自定义属性不属于冲突。绑定中途失败会删除新驱动器与内部数据块，恢复变换、父级、锁定状态及参数。

实时编辑及读取 `cine.*` 仍需要插件已注册。交给不安装插件的环境前，应烘焙为普通位置与四元数关键帧；内部计算数据块会随停用或烘焙清理。

## 验证

### 0.5 紧凑面板与插件设置

侧栏只保留一个常驻面板。操作按钮的 `text` 为空，原生 Operator 名称、描述与轮询提示仍作为悬停说明。参数默认不显示名称，独立图标与数值控件并排绘制，避免直接给无文字数值控件传 icon 导致控件仅显示图标。保留对象名、XYZ 轴标记和必要的错误提示。

AddonPreferences 中提供参数名称开关及新建镜头的距离、焦距、传感器、裁剪和构图默认值。默认值只在一键创建时应用，不能回写已有镜头；裁剪范围无效时通过创建事务回滚。偏好设置不读取或编辑当前镜头。对焦目标、对焦距离、希区柯克主体留在主面板；传感器、裁剪和高级构图留在默认折叠的相机设置子面板，直接编辑原生数据。

设置入口使用 Blender 原生 `preferences.addon_show` 定位当前插件，不修改用户键位。偏好设置模块在核心参数之后、操作和 UI 模块之前注册，卸载时反向注销。相机侧栏及设置子面板沿用相机/曲线/备用相机的统一解析规则。

### 0.4 光学与镜头操作

镜头按钮插帧沿用真实的 Curve/Object/Camera 数据路径。普通模式记录 Curve 变换、`camera.cine.*` 空间参数和 Camera Data 光学参数；不记录已被驱动器控制的基础变换。希区柯克模式记录 Curve 变换及 `control.cine.dolly_travel`，焦距输出仍由联动计算。没有注册任何 Keymap。

焦距、传感器、景深、Shift 和构图参考线均直接操作原生 Camera Data。侧栏将高级光学、构图和希区柯克整理为子面板。局部相机视图与场景渲染相机分别由两个明确操作控制，避免浏览镜头时意外切换渲染相机。

希区柯克在启用时捕获相机在曲线空间的机位、朝向、镜头前向、焦距以及主体光轴深度。它用一个单独的内部光学数据块保存原生驱动器，输入只来自 Curve 及主体：

```text
Curve 变换、捕获机位/朝向、推拉量 → 摄像机增量变换
Curve 变换、捕获机位/前向、推拉量、主体世界位置 → 主体光轴深度
基准焦距 × 当前光轴深度 / 基准光轴深度 → Camera Data Lens
```

光学链不反向读取 Camera evaluated transform，也不读取相机上的空间参数，否则 Lens → Camera Parameters → Transform → Lens 会形成求值循环。相机运动链与光学链独立计算相同的捕获位置，均由 Blender 的原生简单表达式求值，不使用逐帧回调、计时器或 Driver Namespace。

主体指针存在时使用实时位置；没有目标或目标被删除时使用启用时保存的世界锚点。未改变相机本地朝向的轴向推拉维持参考深度平面的投影比例；侧向移动和旋转仍会改变构图。运行时限制焦距为 Camera RNA 合法范围，穿过主体时不再承诺比例保持。

正常停用恢复原空间驱动输出和原焦距动画，不修改原 Lens Action。解绑前可保留当前焦距；烘焙则逐帧采样 evaluated 相机位姿与焦距，移除光学联动后写入普通关键帧。复制完整镜头并独立化时同时重定向空间及光学数据块，避免停用副本影响原镜头。

### 0.6 参考机位反推

`rig.import_camera_position` 读取参考相机当前帧的求值后世界位置，经曲线控制器世界矩阵的逆矩阵转换为控制空间；外部空间原点也转换到同一空间，空原点则使用已保存的控制空间中心。复用 `solve_orbit_from_pose` 反推距离、水平环绕、垂直环绕并清零偏移，不反解参考相机朝向。保留原有基准朝向、摇摄、俯仰、翻滚和瞄准设置。

该操作与归零绑定明确分开，不创建持续依赖、不插帧、不改变参考相机。写入前检查轨道通道的动作、非线性动画和驱动器，以及奇异控制器矩阵和希区柯克状态。写入后通过实际求值位置验证，失败恢复四个输入字段。测试覆盖 40 组相对坐标、非均匀缩放、参考相机父级、极点、重合与动画保护。
