# Cine Controller 1.0

Blender 摄像机空间控制插件。用一个曲线控制器完成整体移动和旋转，通过距离、环绕、摇摄、俯仰和翻滚设计镜头。支持完整位姿反推、样条轨迹、希区柯克变焦、多事件程序化震动及 MCP 自动化。

**版本：1.0.0；目标平台：Blender 5.2 LTS；验证环境：Blender 5.2.3 LTS。**

## 安装与快速开始

1. 从 [GitHub Releases](https://github.com/zhazhayu01/cine-controller/releases) 下载 `CineController-1.0.0.zip`，不要使用仓库自动生成的源码压缩包。
2. 在 Blender“编辑 → 偏好设置 → 插件”中选择“从磁盘安装”，选中 ZIP 并启用 **Cine Controller**。
3. 打开三维视图侧栏（N），进入 **Cine** 标签。
4. 点击顶部创建图标，在 3D 游标处生成已绑定相机和可见曲线控制器。
5. 选中曲线，用 G/R 整体移动和旋转，或在面板中调整镜头参数。

新建镜头默认距离为 5，角度为零，镜头水平朝向控制器中心。创建后选中曲线。已有场景相机时，创建操作不会替换它；点击“进入此相机视图”会将目标设为场景活动相机并进入视角，普通相机和插件相机均使用 Blender 标准切换方式。

## 控制逻辑

| 控制项 | 作用 |
| --- | --- |
| 曲线控制器 | 整套镜头空间的整体移动与旋转 |
| 空间原点 | 环绕的中心，可指定独立对象 |
| 距离 | 控制远近；零角度时沿控制器前后方向移动 |
| 水平／垂直环绕 | 围绕中心改变机位；垂直环绕负值升高、正值降低 |
| 空间偏移 | 按镜头右、上、前方向补充位移 |
| 摇摄／俯仰／翻滚 | 改变相机自身朝向，不依赖瞄准目标 |
| 焦距、景深与构图 | 每台相机独立保存的原生光学参数 |

相机基础位置、旋转归零并锁定，最终变换由插件内部计算。内部计算不创建隐藏辅助物体。选中控制器即可调整对应相机；选择其他物体时，面板可继续操作指定的备用相机。

给普通相机“启用控制器”会清零基础变换和控制角度，不保留原画面。需要沿用已经摆好的机位时，使用完整位姿反推。

## 完整位姿反推

用独立自由相机摆好位置和朝向，选中目标控制器，在面板顶部指定“参考相机”，点击右侧导入图标。

反推相对控制器和空间原点，计算距离、水平／垂直环绕、摇摄、俯仰和翻滚，并清零空间偏移。参考相机不被修改，焦距、景深和构图不复制，不自动建立持续跟随或插帧。

反推前停用震动和希区柯克。已有待写入参数的动画或驱动器时拒绝覆盖。控制器需要正向等比缩放且无剪切。角度可能存在等价解，以最终位姿一致为准。

## 样条轨迹

1. 创建独立曲线，确保只包含一条样条。
2. 选中控制器，展开“样条轨迹”，选择曲线并绑定。
3. 调整进度：0 是起点，1 是终点。需要沿切线转向时，开启“跟随轨迹朝向”。
4. 在不同帧设置进度，点击顶部镜头插帧图标记录动画。

轨迹移动的是控制器中心，相机的距离、环绕和偏移仍生效。要让相机本身落在轨迹上，将距离和空间偏移归零。绑定会清零控制器平移；已有控制器变换动画、驱动器或约束时拒绝覆盖。

暂停保留当前帧机位和进度动画，恢复后继续求值；暂停时可改绑另一条轨迹。进度采用 Blender 原生曲线参数，不提供额外匀速重采样。

## 光学、构图与插帧

主面板提供焦距、景深、对焦目标、对焦距离和光圈。指定对焦目标后，手动距离不生效。构图图标控制三分线、中心线、安全框和画幅外遮罩，参考线不进入最终渲染。

投影方式、传感器、裁剪和镜头偏移在折叠的“相机设置”中。齿轮设置只保存通用显示选项和新建预设，不修改已有镜头。

顶部镜头插帧按钮记录当前模式的控制器、空间与光学参数；轨迹模式记录进度，希区柯克模式记录联动距离和推拉，震动启用时还记录总强度。外部驱动器输出会跳过，不覆盖。插件不新增快捷键。

## 高级效果

“高级效果”和子面板均默认折叠。

### 希区柯克变焦

在“高级效果 → 希区柯克变焦”中选择主体并启用，直接调整主面板“距离”：减小推进，增大后退，焦距自动补偿。附加推拉可叠加使用。停用返回基础运镜，需要保留效果时使用烘焙。

几何主体按投影包围盒高度补偿，高度退化时使用宽度；参考点按光轴深度补偿。保持的不是三维物体所有内部透视和轮廓。主体穿过镜头或焦距达到极限时会提示，此时无法继续保证大小。仅支持透视相机，相机数据须独立且焦距没有外部驱动器；联动期间不要改变传感器或投影方式。

### 程序化震动

在“高级效果 → 程序化震动”中启用，首次启用会在当前帧创建一次冲击。

- **多次冲击：** 到下一次落地帧点击事件列表加号；事件独立计时，重叠时叠加，可单独启停、复制和删除。
- **常用参数：** 开始帧、持续帧数、强度、频率、衰减。总强度统一控制所有事件，可插帧；0 为不震动。
- **持续振动：** 把事件模式改为“持续”，首尾平滑淡入淡出。
- **轴向细调：** 展开“方向与随机”，设置右／上／前位移、俯仰／摇摄／翻滚角度与种子。

震动按绝对时间求值，同一帧和同一种子结果一致。震动叠加在基础运镜后，可与轨迹共用；希区柯克补偿使用未震动的机位，不产生焦距呼吸。停用保留事件，烘焙可输出最终震动动画。

## 烘焙与交付

“烘焙为关键帧”使用场景起止帧，逐帧采样最终位姿，输出普通相机位置与四元数动画；希区柯克启用时同时输出焦距。相机随后解除控制器，控制曲线和轨迹保留供整理。

实时控制工程需要启用插件，交给未安装插件的环境前请先烘焙并核对镜头。复制镜头后若提示共享计算数据，先执行独立化；多个相机共用光学数据时，另将相机数据设为单用户。

## Blender MCP

`bpy.ops.cine.automation` JSON 接口可查询镜头、设置参数、插帧、反推、绑定轨迹、管理高级效果和烘焙。角度统一使用度，每次明确指定相机或控制器名。

在齿轮设置点击“复制 MCP 接入指令”，交给 AI 客户端；支持项目 `AGENTS.md` 的客户端也可读取仓库规则。详见 [MCP 接入说明](docs/MCP接入说明.md)。
